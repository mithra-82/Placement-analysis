# 🎓 College Placement Analytics Dashboard

## 📌 Project Overview

This project focuses on analyzing college placement data using Tableau. The dashboard provides visual insights into student placement performance and recruitment trends.

## 🎯 Project Objectives

- Analyze overall college placement performance.
- Understand student placement trends.
- Explore salary and recruitment patterns.
- Visualize placement statistics through interactive dashboards.
- Support data-driven placement analysis.

## 🛠️ Tools Used

- Tableau
- Data Visualization
- Data Analytics
